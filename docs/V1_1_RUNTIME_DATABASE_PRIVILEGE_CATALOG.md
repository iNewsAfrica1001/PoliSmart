# PoliSmart Africa AI V1.1 Runtime Database Privilege Catalog

**Status:** Repository policy — Production execution not authorized

The normal application uses the pooled `polismart_runtime` identity. This catalog is derived from
the current authentication service and repositories, not from blanket CRUD assumptions. Every
table created by migrations `0001` through `0014` appears below. UUID defaults use `gen_random_uuid()`;
the migrations create no application sequences, so runtime sequence privileges are not required.

`CREATE` are forbidden for `polismart_runtime`. Migration `0015_runtime_privilege_catalog` first
revokes all table privileges and then grants this exact policy. No sequence privilege is granted.
